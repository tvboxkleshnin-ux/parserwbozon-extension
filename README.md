# PARSERWBOZON — расширение Chrome

Браузерное расширение для отслеживания цен WB / Ozon / Я.Маркет / AliExpress / Pepper и отправки в PARSERWBOZON (NAS `:5000`).

На карточках AliExpress дополнительно сравнивает цену (+ таможенную пошлину) с закупочными каталогами поставщиков.

## Установка

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика**
3. **Загрузить распакованное расширение** → выберите эту папку
4. В popup укажите API: `http://192.168.0.45:5000` (или ваш NAS)

## Возможности

- Автодобавление товара в отслеживание с карточки
- История цены / цель / продавцы WB
- AliExpress: пошлина «Таможенная пошлина ≈… ₽», сравнение с поставщиками по конфигурации памяти (в т.ч. при выборе SKU)

## Требования

- Запущенный UI PARSERWBOZON на NAS (`app.py`, порт 5000)
- Парсер может работать на ноутбуке отдельно — расширению нужен только API на NAS
